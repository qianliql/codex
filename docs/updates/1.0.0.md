# 轻账本 1.0.0：分类、收入统计与自动记账优化

更新日期：2026-10-14，北京时间

## 本次变化

- 录入账单时分类改为两列换行完整展示；不常用分类单独常显，修复展开时原有分类消失的问题。金额从小数点开始输入时自动补上 `0`。
- 分类管理移除拖动，点击分类即可修改重要度；常用分类上限为五个。升级后超出的常用分类移入不常用，保留分类和历史账单的关联。不常用分类与其他组一样始终显示；已满的重要度选项使用更明显的深灰色并不可选。分类弹窗显示后立即绑定保存事件，修复快速点击时可能没有保存的问题。
- 统计顶部加入总收入；收入按分类显示圆环、明细和单笔排行，与支出图的展示规则一致。
- 支付宝只有一笔、明确付款结果和可靠金额的汇总通知可尝试识别；多笔汇总、日报月报、金额不明确的通知仍跳过。后台通知处理按到达顺序执行，并在本机诊断中显示处理阶段耗时。
- 正式安装包启用代码与资源压缩，只包含 ARM 32 位和 64 位架构，保留离线中文 OCR 和原安装签名。

## 使用方法

覆盖安装同签名旧版后，进入新增账单或分类管理即可看到新的分类展示。统计页顶部查看总收入，向下查看分类收入图。自动记账结果与处理耗时可在“我的 → 设置 → 自动记账 → 诊断”查看。

## 已知限制

- 当前手机已拔线，尚未在 1.0.0 上做真机覆盖安装或支付宝真实支付验收。支付宝的本次修改依据旧版诊断“汇总通知，已跳过”，没有取得被跳过通知的正文，不能确定该消息就是用户漏记的那笔。
- ColorOS 可能清理后台进程；半小时 USB 供电观察不足以证明所有长期闲置场景都能持续监听。
