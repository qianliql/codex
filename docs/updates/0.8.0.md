# 轻账本 0.8.0：录入布局与分类管理大更新

更新日期：2026-10-10（北京时间）

## 本次变化

- 新增账单删除“记录每一笔，慢慢看清生活”。备注放到主表单，商户及“记住这个商户的分类”移入“更多”；更多还包含时间和标签。收起更多后仍保留已经填写的商户内容。
- 分类区排成两行，保留分类图标、通知栏/常用优先排序及不常用折叠。分类较多或字体放大时可左右滑动，避免继续占用纵向空间；编辑时自动显示已选择的不常用分类。
- 新增账单支付方式仅显示微信、支付宝、银行卡、现金，等宽排在一行；窄屏大字体时按可用宽度调整字号，保持文字完整。历史账单原有“其他”支付方式保持原值；编辑时不主动选择新支付方式，就不会改写原值。
- 首页、我的、账单和统计切换加入短暂淡入及轻微位移；独立页面打开和返回加入淡入淡出。页面动画尊重系统关闭动画的设置。
- 所有实际分类均可删除，包括原本受保护的默认分类。右侧“⋮”菜单保留上移、下移，统一提供删除分类。
- 删除前二次确认，显示受影响的账单数量和商户自动分类规则数量。取消不会写入；确认后相关账单变为未分类，账单本身、金额、备注、标签与退款关联保留，使用此分类的商户规则同时删除。
- 长按普通分类，直接选择通知栏、常用、不常用三种重要度；通知栏最多3个、常用最多8个，超过限制会提示并保留原分组。点击分类仍可编辑名称与图标。
- 备份恢复按照备份里的分类列表恢复，避免重新补回已经删除的默认分类。允许没有“未分类”实体或分类列表为空的合法备份；所有分类删除后仍能手工记账。

## 使用方法

1. 新增账单填写金额、分类和备注，直接点选一行支付方式；需要商户、时间或标签时展开“更多”。
2. 在“我的→分类管理”长按分类，选择重要度。不常用分类可先展开；组内顺序继续通过右侧“⋮”中的上移、下移调整。
3. 删除分类时点右侧“⋮→删除分类”，核对影响数量后点“确认删除”。删除后可重新为未分类账单选择分类。
4. “未分类”实体也可以从右侧菜单删除；账单没有分类时仍显示“未分类”，这是账单状态提示，不是删除失败。该提示不参与重要度分组。
5. 备份与恢复仍在“我的→数据管理”。恢复会替换当前本机数据；删除基础分类后的新备份请用0.8.0或之后版本恢复。
