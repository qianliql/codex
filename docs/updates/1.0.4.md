# 轻账本 1.0.4：账单返回位置与离开提示

更新日期：2026-10-16，北京时间

## 本次变化

- 删除一笔账单或批量删除后，账单列表回到操作前浏览的位置附近，不再跳回顶部。
- 长按账单进入批量选择后，退出时保留列表位置。已选账单时按系统返回或点退出，会先确认是否取消选择；退出选择不会删除账单。
- 新增或编辑账单有未保存改动时，左上角返回和系统返回手势会询问“保存”“不保存”或“继续编辑”。

## 使用方法

在账单页打开或长按账单。编辑后使用左上角或系统返回可选择保存、放弃或继续；批量选中后返回可确认退出。删除后的列表会尽量对齐原来位置附近的下一笔账单。

## 验证结果

- `assembleDebug`、`testDebugUnitTest`、`assembleRelease` 成功；38 组 276 项检查，0 失败、0 错误、0 跳过。模拟测试覆盖编辑未保存提示、单笔及批量删除后的返回位置，以及两笔选中后取消和确认退出。
- OPPO PFEM10 / ColorOS 16 已从 1.0.3 同签名覆盖安装 1.0.4，系统显示 versionCode30。真机选中两笔后按返回，出现“退出批量选择？”及“继续选择”“退出选择”；分别操作后账单页仍在原处。打开现有账单时直接显示“编辑账单”。没有删除或保存真实账单。
- 核对正式 APK 包名、版本、系统要求、原签名及 SHA-256。

## 已知限制

- 真机检查期间手机切换到其他应用，编辑页修改后使用侧滑返回的提示尚未在真机完成核对；该流程已由模拟测试覆盖。删除后的定位也仅做模拟测试，未为验收删除真实账单。
- 其他手机系统及长列表所有筛选条件下的返回位置未逐一实测。
