# 轻账本 1.0.5：监听中断后的付款保存

更新日期：2026-10-17，北京时间

## 本次变化

- 微信或支付宝通知已经识别出可靠单笔金额时，先把待写入账单暂存在应用私有空间；账本写入完成后立即清除。若系统在写入前结束监听进程，重连后继续保存，重复通知仍只生成一笔账单。
- 自动记账诊断保留最近的微信、支付宝处理结果和时间，方便在之后的通知覆盖“最近处理”时继续排查。记录不含通知正文、金额或商户。

## 使用方法

正常开启“我的 → 设置 → 自动记账”的通知读取与后台保护即可。漏记时可打开该页的“诊断”查看最近处理记录，并核对系统通知是否曾出现；不需要重复付款测试。

## 验证结果

- `assembleDebug`、`testDebugUnitTest`、`assembleRelease` 成功；39 组 280 项检查，0 失败、0 错误、0 跳过。模拟测试覆盖暂存付款在监听重连后入账一次、清除待写入记录，以及后续通知不覆盖先前处理结果。
- OPPO PFEM10 / ColorOS 16 的系统退出记录显示，旧版监听进程曾在用户报告漏记的付款时段被系统结束，随后重建。诊断中没有该笔成功记账记录；当时的系统通知已消失，无法判定它是否到达过监听回调，也无法取回金额。用户选择不补录，本次没有修改那笔历史账单。
- 同一手机已从 1.0.4 同签名覆盖安装 1.0.5，系统显示 versionCode31；通知读取授权和监听组件仍在系统绑定列表。没有为本次验证增加真实账单。
- 本版未进行新的真实付款验收；模拟重连不能代表厂商清理后的通知一定送达。

## 已知限制

- 暂存只保护**已经送达并解析出可靠金额、尚未写入账本**的通知。系统未投递通知、监听断开期间通知消失、通知本身没有可靠单笔金额时，应用仍无法自动补回；ColorOS 可能继续结束后台进程。
- 尚未在其他手机系统上验证长时间待机及真实支付通知。诊断只保留最近 24 次处理结果，超出后按时间淘汰。
