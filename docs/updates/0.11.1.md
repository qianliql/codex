# 轻账本 0.11.1：Gitee 安装包镜像

更新日期：2026-10-13，北京时间

## 本次变化

- 应用仍从公开 GitHub Release 读取版本号、更新内容、安装包大小和 SHA-256；下载新版 APK 时优先尝试公开 Gitee 镜像。镜像连接失败、下载不完整或 SHA-256 不符时，自动改用 GitHub。
- 更新页显示两个下载源。镜像切换时进度重新计数；下载错误记录在本机应用日志，便于排查，不记录账单或支付通知正文。
- 安装前继续验证 APK 的大小、SHA-256、包名、版本号、最低系统要求，以及与已安装轻账本一致的签名。安装仍由 Android 系统确认。

## 使用方法

1. 从 [GitHub 正式版](https://github.com/qianliql/codex/releases/tag/v0.11.1) 或 [Gitee 镜像](https://gitee.com/qianlihuo/money/releases/tag/v0.11.1) 下载本版 APK，并覆盖安装同签名旧版；不要卸载。
2. 从本版开始，后续“我的 → 设置 → 检查更新”会优先使用 Gitee 下载 APK，失败时尝试 GitHub。已安装的 0.11.0 不会自动获得新的下载逻辑，须先覆盖安装本版。

## 已知限制

- 版本检查仍依赖 GitHub 元数据；GitHub 接口完全不可达时，应用内无法获知新版本，可手动打开 Gitee 发行版下载。两个下载源都失败时，更新页会提示重试。
- 厂商省电或清理应用仍可能导致通知监听中断。此次 USB 中断期间没有可靠的监听连续性结论，长期待机和真实支付不在本次下载源变更的验收范围内。
