# 轻账本 1.0.3：支付宝通知中的红包金额

更新日期：2026-10-15，北京时间

## 本次变化

- 修复支付宝单笔支出通知同时含付款金额和领取红包金额时，被误判为两个付款金额冲突、漏记账单的问题。红包、优惠券和积分前的金额不作为交易金额。
- 仍要求通知能明确证明单笔交易并提供可靠正数金额；只有促销金额、没有金额或真正有两个不同付款金额的消息继续跳过，不生成零元账单。

## 使用方法

同签名覆盖安装后，保持“我的 → 设置 → 自动记账”的通知读取权限和监听连接。支付宝发来明确的单笔支出通知时自动记账；在账单页核对金额和支付方式。已经从系统通知栏消失的旧付款通知不会自动补录，可手动新增。

## 验证结果

- `assembleDebug`、`testDebugUnitTest`、`assembleRelease` 实际成功。38 组 273 项检查，0 失败、0 错误、0 跳过。新增回归检查使用虚构金额，覆盖单笔支出附带流量红包、货币符号红包、纯促销消息、无金额消息和两个真实支出金额的歧义消息。
- OPPO PFEM10 / ColorOS 16 从 1.0.2 同签名覆盖升级至 1.0.3，系统显示 versionCode29。升级前系统通知栏留有一条真实支付宝单笔支出通知，正文同时有交易金额和红包金额；升级后软件生成快捷分类提示，用户核对账单只新增一笔支出，金额正确，支付方式为支付宝。没有为测试额外付款，也没有清除账单。
- 核对 APK 包名、versionCode29、minSdk26、原签名证书与 SHA-256。

## 已知限制

- 本次真机验收覆盖保留在通知栏中的一条真实支付宝单笔付款提醒，不代表支付宝所有通知格式、其他手机系统或长期闲置后的监听均已验证。旧订单若通知已消失，不能依靠本次升级自动恢复。
