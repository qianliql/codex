# 轻账本 0.7.0：简洁导航、搜索重置与监听提醒

更新日期：2026-10-10（北京时间）

## 本次变化

- 底部导航只保留“首页”和“我的”。首页“看账单”、最近账单旁“全部”进入账单页；“查看统计”进入统计页。
- 账单/统计页可通过系统返回键或底部“首页”回到首页；从首页长按账单仍可进入对应月份并选中该账单。切到“我的”后清理详情页返回层级，界面重建保留当前详情页。
- 账单“更多”菜单删除“刷新账单”和“清除筛选（保留日期）”，继续支持下拉刷新。
- 搜索生效后，放大镜旁显示“重置”；待处理筛选也可用该按钮退出。重置清除关键词、分类、标签、支付方式、来源、类型和待处理条件，并恢复当前选定月份的完整账单。不限日期或自选范围搜索后，重置回到之前选定月份。
- 搜索时顶部为按钮腾出空间，保留月份栏、记一笔与更多操作；退出搜索恢复“账单”标题。筛选状态与重置入口随页面状态保存。
- 保留通知读取权限未开启的提醒，补充“已授权但监听未连接”的提醒。软件在前台时每2秒检查权限/连接，先请求自动重连；连续未连接超过5秒后提示关闭再开启通知读取，按钮直接打开对应系统授权页（不支持时退回通知访问列表）。连接恢复后自动隐藏。
- “我的”中显示未开启、等待监听连接或监听已连接，避免把授权状态直接当作连接成功。已退休的漏记检测、通知样本和诊断导出继续存档。

## 使用方法

1. 从首页打开账单或统计；点底部“首页”或系统返回即可回去。
2. 点账单顶部放大镜设置搜索条件。结果页点旁边“重置”，恢复选定月份；下拉列表仍可刷新，左右箭头与点击日期的年月选择继续可用。
3. 打开软件后，若出现“监听未连接，请关闭再开启通知读取”，点“重新开启”，在系统页将轻账本的通知读取关闭再开启。权限未开启时点“去开启”，允许通知读取。系统授权仍须本人确认。

## 已知限制

监听连接成功不能保证每笔支付都会有可读取通知。权限、系统后台限制以及微信/支付宝是否产生含金额的单笔通知仍会影响记账。状态提醒在软件前台运行，不能在软件进程被系统终止时自行检测；没有重新加入后台漏记检测或通知内容采集。
