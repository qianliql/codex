# 轻账本 0.3.0：收支与分类直接点选

记录日期：2026-10-01（北京时间）。历史报告于2026-10-10根据已有开发/验收记录整理。

## 本次变化

- 新增账单使用收入/支出切换，金额、分类和详情分组。
- 八项预设分类及支付方式改为直接点选。
- 分类升级移除旧预设并保留自定义分类；退款和转账在适用的编辑/识别确认场景显示。

## 使用方法

根据“本次变化”中的对应页面操作。当前完整安装方法见README.md；旧版报告用于回顾功能演进。

## 验证结果

构建和单元测试通过；该轮没有手机显示复核。

## 已知限制

旧分类升级涉及数据迁移，升级前应保留备份。

## 安装与数据兼容性

0.4.1及之后交付使用同一签名。原电脑0.4.0使用不同签名。升级前导出本地备份，不要自行卸载已有账本。
