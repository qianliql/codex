# 轻账本 0.10.0：统计返回、自动支付方式与待确认金额大更新

更新日期：2026-10-12，北京时间

## 本次变化

- 统计页左上角增加返回箭头；月度、年度及页面重建后均可返回首页。
- 微信通知生成的账单选择微信，支付宝通知生成的账单选择支付宝。本版开始记住最近识别成功的支付方式，手动新增时优先预选，仍可改为其他可选方式；未识别过时沿用微信默认。
- 日报、月报、汇总、失败、待支付、没有可靠金额或金额冲突的通知不改变预选方式，也不生成零元账单。恢复监听时回读的旧通知不会覆盖较新的识别结果。
- 首页增加“待确认金额”快捷卡片与实时笔数，点击查看所有月份中金额为0且状态为待确认的历史账单；金额明确但尚未分类、未关联退款等普通待处理账单不混入。
- 点击账单补齐金额、保存或删除后，列表与首页笔数更新。保留分页、搜索、月份切换及长按多选；搜索的更多条件可取消待确认金额筛选，旁边重置按钮可回到所选月份的普通账单。筛选时返回箭头也固定在左上角。

## 使用方法

1. 覆盖安装本版并打开一次。统计页左上角箭头返回首页。
2. 通知读取开启且成功识别付款后，从“记一笔”进入会优先选择最近识别的微信或支付宝；手动选择优先于预选。编辑已有账单保留其原支付方式，截图有识别结果时优先使用截图方式。
3. 首页点击“待确认金额”；进入时默认全部月份。点账单填写真实金额并保存，或长按按现有确认流程删除。0笔时保留入口并显示空状态。
4. 搜索→更多条件→“只看待确认金额”可调整此筛选；账单顶部“重置”恢复所选月份的普通列表。

- 本次没有连接手机，未做真实付款、覆盖安装、闲置锁屏、最近任务清理或电量实测；HONOR X10 Max/HarmonyOS3.0与ColorOS16未有本轮真机结果。
