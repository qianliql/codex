# 轻账本 1.0.1：恢复四列分类与按需展开

更新日期：2026-10-14，北京时间

## 本次变化

- 新增和编辑账单中的常用分类恢复为每行四个，缩短表单高度；窄屏上按可用宽度缩放分类文字和图标，保留完整分类名称的辅助说明。
- 不常用分类默认收起，点“展开不常用分类”后显示；收起或展开不影响已显示的常用分类。编辑原本属于不常用分类的账单时自动展开并选中原分类。
- 1.0.0 的收入统计、通知处理、常用分类五个上限及其他数据规则保持不变。

## 使用方法

同签名覆盖安装后，在“首页 → 记一笔”查看每行四个的分类；需要不常用分类时点分类下方的展开按钮。修改历史账单时若原分类不常用，页面会自动展示它。
