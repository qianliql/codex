# 轻账本 0.1.0：基础离线记账

记录日期：2026-10-01（北京时间）。历史报告于2026-10-10根据已有开发/验收记录整理。

## 本次变化

- 提供手动新增、编辑、删除账单、分类、标签与商户分类规则。
- 增加微信/支付宝通知监听、本地中文OCR、单张和批量截图导入。
- 提供月度/年度统计、退款关联、搜索筛选、CSV导出与JSON备份恢复。

## 使用方法

根据“本次变化”中的对应页面操作。当前完整安装方法见README.md；旧版报告用于回顾功能演进。

## 验证结果

首轮在OPPO Find X5 Pro / Android16检查手工账单、退款关联、分类规则、导出恢复及虚构截图OCR；App不申请INTERNET权限。

## 已知限制

旧记录没有完整的逐版本测试数量。不同平台通知、长期后台及电量仍需实际使用观察。

## 安装与数据兼容性

0.4.1及之后交付使用同一签名。原电脑0.4.0使用不同签名。升级前导出本地备份，不要自行卸载已有账本。
