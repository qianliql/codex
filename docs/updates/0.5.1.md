# 轻账本 0.5.1：改名、录入与长按批量删除

记录日期：2026-10-09（北京时间）。历史报告于2026-10-10根据已有开发/验收记录整理。

## 本次变化

- 分类改名使用输入弹窗，就地提示空白/重名，保留原分类关联。
- 新增账单金额和分类前置，保存按钮固定底部，附加详情可展开。
- 首页与账单支持长按多选、全选已加载、数量确认、取消与批量删除。
- 批量删除保持事务，保留退款解除关联并待确认，标签关联正确处理。
- 通知优先当前正文，避免短文、展开文字、余额和历史金额拼接冲突；微信和支付宝分别记录诊断结果。

## 使用方法

根据“本次变化”中的对应页面操作。当前完整安装方法见README.md；旧版报告用于回顾功能演进。

## 验证结果

43项测试通过，包含超过999笔选择、后续分块失败回滚、分类关联、通知结构、改名错误提示及窄屏/大字体/键盘。

## 已知限制

合成通知测试不代表用户实际付款漏记根因已确定。后续用户反馈重新授权后转账恢复。

## 安装与数据兼容性

0.4.1及之后交付使用同一签名。原电脑0.4.0使用不同签名。升级前导出本地备份，不要自行卸载已有账本。
