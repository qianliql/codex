# 轻账本 1.0.2：支付宝单笔提醒与分类拖动排序

更新日期：2026-10-15，北京时间

## 本次变化

- 修复支付宝“你有一笔明确金额的支出”通知附带领取积分提示时被当作促销消息跳过的问题。只有能确定单笔交易与正数金额时才记账；纯积分、日报月报、待支付与失败消息继续跳过。
- 分类管理支持长按分类并拖到同一组内的目标位置，中间分类依次移动；拖到列表边缘时缓慢滚动。通知栏、常用、不常用、收入四组各自排序，拖动不改变重要度或已有账单分类。
- 分类行的三个点菜单只保留“删除分类”，继续显示删除前二次确认。
- “标签管理”移到“我的 → 设置 → 标签管理”。

## 使用方法

同签名覆盖安装后，打开“我的 → 分类管理”，长按分类并拖到同组的新位置。点击分类可编辑名称、图标和重要度；点三个点可删除。管理标签请进入“我的 → 设置”。支付宝自动记账仍需在设置中授权通知读取并保持监听连接。

## 验证结果

- `assembleDebug`、`testDebugUnitTest` 和 `assembleRelease` 实际成功。38 组 272 项自动检查，0 失败、0 错误、0 跳过。新检查覆盖支付宝交易提醒附带积分提示、纯促销过滤、分类同组排序、跨组拒绝、账单关联不变、设置入口及分类页面回归。
- OPPO PFEM10 / ColorOS 16 从 1.0.1 同签名覆盖升级到 1.0.2，系统显示 versionCode28。应用内监听显示“已连接”；“标签管理”在设置中，分类长按从首位拖到第三位后顺序随之移动，再拖回首位并核对原顺序；三个点菜单只显示“删除分类”。未删除或修改真实账单。
- 上一笔漏记的真实支付宝通知曾在手机系统中读到“交易提醒”及单笔支出附带积分提示。修复使用相同句式、虚构金额的合成通知回归检查；安装本版时该通知已从系统通知列表消失，无法在 1.0.2 中重新投递或核对实际入账。没有为测试新增付款。
- APK 已核对包名、versionCode28、minSdk26、原签名证书与 SHA-256。

## 已知限制

- 1.0.2 尚未接收新的真实支付宝付款通知，因此不能据合成通知检查断言所有支付宝通知都能自动记账。其他 ColorOS 版本、HarmonyOS 及长期闲置后的监听也未在本版实测。
- 列表边缘缓慢滚动逻辑已实现，真机已核对同组拖动与位置保存；长列表边缘持续拖动速度尚未单独实测。
