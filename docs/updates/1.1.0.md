# 轻账本 1.1.0：聚合账单与金额计算

更新日期：2026-11-10，北京时间

## 本次变化

- 在账单页长按进入多选后增加“聚合”。选中至少两笔同类型、已确认金额的账单，打开预填的新账单页：金额相加，时间取最晚的一笔，支付方式按出现笔数最多的方式选择；出现次数相同取最近一笔的方式。分类按笔数预选，原备注与标签带入。填写聚合备注、核对后确认，用新账单替换原账单。
- 新增、编辑和聚合账单的金额旁增加小型“计算”入口，支持加、减、乘、除并预览结果；结果按分四舍五入，非正数不能保存。
- 搜索页分类改为四列布局；展开不常用分类后，常用分类继续显示，所有不常用分类完整换行显示。
- 聚合在单次数据库事务中保存新账单、标签与通知去重标记，再删除原账单。失败时全部回滚，避免原账单丢失或原通知重连后重复入账。

## 使用方法

在账单列表长按一笔，再点选其他账单，点击“聚合”。检查预填金额、日期、分类和支付方式，填写备注后点击“保存并替换”，在确认框中完成操作。已关联退款、金额待确认或不同收支类型的账单需先分别处理，不能一起聚合。金额计算入口在新增或编辑账单金额的右上方。

## 已知限制

- 聚合后原账单的逐笔金额、原始通知和商户细节不再作为独立账单显示；原备注会预填到新备注中，可在保存前修改。建议先检查所选账单，保存前会再次确认。
- 关联退款的支出或退款本身不能聚合，以免破坏退款对应关系。不同类型账单需分开聚合。尚未在荣耀 X10 Max / HarmonyOS 3 真机验证该页面。
