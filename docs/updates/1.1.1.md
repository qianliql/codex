# 轻账本 1.1.1：修复金额计算输入框文字重叠

更新日期：2026-11-11，北京时间

## 本次变化

- 金额计算弹窗把“计算数值”放到输入框上方，输入框内只显示“例如 5 或 0.8”，消除两条提示重叠。

## 使用方法

在新增、编辑或聚合账单时，先输入原金额，再点金额旁的“计算”。选择加、减、乘、除并输入数值，核对预览后点“应用”。
