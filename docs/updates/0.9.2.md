# 轻账本 0.9.2：闲置后的监听恢复与后台保护

更新日期：2026-10-11，北京时间

## 本次变化

- 修复旧版断开仅立即请求一次重连，后续检查依赖前台页面的问题。现在不打开页面也有退避重试和系统持久化恢复任务。
- 手机重启、覆盖更新、进程存活时亮屏或解锁会检查连接；已连接时停止重试，撤销通知读取授权时停止恢复任务。
- “我的 → 自动记账”增加可开关的后台保护。开启后显示无声音的常驻连接状态通知，并在后台检查断开情况；默认关闭，由用户选择开启。
- 增加“允许后台运行”入口，直接请求系统电池优化豁免，系统不支持时退回电池设置或应用设置；针对华为/荣耀提供应用启动管理指引。
- 监听断开横幅改为“正在自动重连”，提供重连、后台设置和通知权限三个处理入口。
- 重连后重新读取仍留在通知栏中的微信/支付宝支付通知，沿用通知唯一键防止重复入账；日报、月报、汇总和无可靠金额的消息仍跳过。
- 监听服务重建不会取消已经排队的账单保存；旧监听实例的断开/销毁不会清空新实例连接状态。

## 使用方法

1. 下载本版安装包覆盖安装，然后打开一次轻账本。
2. 在“我的 → 自动记账”允许通知读取，打开“后台保护”。如果系统询问是否允许发送通知，请允许，常驻通知会显示实际连接状态。
3. 点“允许后台运行 → 允许不受限”，在系统弹窗确认。华为/荣耀还请在系统“应用启动管理”找到轻账本，关闭自动管理，允许自启动、关联启动和后台运行。
4. 后台保护可以随时关闭；关闭后保留普通的自动恢复任务。数据管理仍只有备份和从备份恢复。
5. 闲置后未记账时先保留支付通知。恢复连接后可以读取仍存在的通知；不需要为测试额外付款。

## 已知限制

- 本次没有连接真机；HONOR X10 Max / HarmonyOS 3.0、OPPO的长期锁屏、实际系统清理、重启和真实付款未实机验收，无法承诺所有系统持续监听。
- 系统持久化任务是恢复后备，执行时间受省电模式及系统调度影响；15分钟是任务间隔，并非每15分钟一定执行。后台保护不使用唤醒锁，设备深度休眠时检查也可能延迟。
- 厂商后台限制、用户强行停止应用、撤销授权仍可能中断自动记账。系统权限必须由用户确认；应用不会自行绕过设置。
- 已消失的通知、未产生通知或通知未包含可靠单笔金额，无法从微信/支付宝内部读取并补回。恢复只处理通知栏中保留的可读通知，不是历史账单同步。
- 开启后台保护会维持前台服务和常驻状态通知，可能增加一些后台耗电；未测量真机电量差异。

实现依据：[Android通知监听生命周期](https://developer.android.com/reference/android/service/notification/NotificationListenerService)、[系统任务与重启持久化](https://developer.android.com/reference/android/app/job/JobInfo.Builder)、[省电模式限制](https://developer.android.com/training/monitoring-device-state/doze-standby)、[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)、[后台启动限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)及[华为后台运行指引](https://consumer.huawei.com/en/support/content/en-us00428704/)。
