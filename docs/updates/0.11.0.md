# 轻账本 0.11.0：设置与应用内更新大更新

更新日期：2026-10-12，北京时间

## 本次变化

- “我的”保留主题配色、分类、标签和商户规则，页面底部显示当前版本；新增“设置”入口，减少首页级菜单密度。
- 设置页集中放置备份账本、从备份恢复、自动记账权限、后台保护、后台运行指引和版本信息。备份及恢复仍是数据管理中的两个操作。
- 增加应用内更新页：检查公开GitHub正式版本、查看更新内容和下载进度，下载后交给Android系统确认安装。应用打开时也会定期检查，手动检查可随时重试。
- 下载前核对Release与`app-update.json`的版本、安装包名称、大小及摘要；下载后校验文件大小、SHA-256、包名、版本号、最低系统要求和本机安装签名。验证失败不进入系统安装页。
- 为更新功能增加`INTERNET`和`REQUEST_INSTALL_PACKAGES`。账单、备份、支付通知、诊断和OCR仍在本机处理，不上传到GitHub。

## 使用方法

1. 从0.10.2或更早版本升级时，先到[GitHub版本下载页](https://github.com/qianliql/codex/releases/latest)下载0.11.0 APK并覆盖安装。0.11.0开始提供应用内更新入口。
2. 打开“我的 → 设置 → 检查更新”。有新版本时阅读说明并点“下载更新”；下载完成后点“安装更新”。
3. 首次使用时依系统提示允许轻账本安装更新，再由系统安装界面确认。若暂时离线，可继续使用账本，稍后重试。
4. 自动记账和备份恢复现在位于“我的 → 设置”。系统通知读取与后台运行授权由用户在原系统页面管理；备份恢复会替换当前本机数据，操作前确认备份内容。

## 已知限制

- GitHub无法访问或受限时，应用内检查或下载会失败；可稍后重试或在浏览器打开版本页。它是打开应用时的定期查询，不是即时推送；用户仍需确认下载与系统安装。
- 本版没有修改微信/支付宝通知解析和后台恢复策略。此前观察到厂商从最近任务清理应用时仍可短暂中断监听；恢复只可能回读仍保留的通知，不能保证任何系统状态下都不漏记。
- 长期闲置、真实付款、支付宝通知、HarmonyOS3.0等场景尚未在本版验收；新增更新功能不代表厂商后台清理问题已消失。

## 安装与数据兼容性

- versionName `0.11.0` / versionCode `23`，minSdk26、targetSdk35、compileSdk36。Room schema10、备份v4不变；继续读取v1/v2/v3/v4备份。本版入口调整与更新功能不迁移账单数据。
