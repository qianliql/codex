# 轻账本 0.11.2：账单编辑与返回位置

更新日期：2026-10-14，北京时间

## 本次变化

- 打开已有账单时，页面第一次显示就使用“编辑账单”标题；读取账单期间暂不显示空白录入表单，避免短暂闪出“新增账单”。待确认金额的账单读完后仍显示“确认金额”。
- 从编辑页返回账单列表时，刷新后的列表回到原先浏览的账单和屏幕偏移；账单位于后续分页时，先加载到该位置。保存时若账单日期或筛选条件导致原账单不再出现在列表，则回到原先的列表位置附近。

## 使用方法

从 [GitHub 正式版](https://github.com/qianliql/codex/releases/tag/v0.11.2) 或 [Gitee 镜像](https://gitee.com/qianlihuo/money/releases/tag/v0.11.2) 下载并覆盖安装同签名旧版。在首页打开“账单”，滑到任意一笔已有账单，打开并修改或直接返回。列表会停留在原来的浏览位置。新建账单仍显示“新增账单”。
