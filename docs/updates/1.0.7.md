# 轻账本 1.0.7：修复支付宝优惠通知漏记

更新日期：2026-10-19，北京时间

## 本次变化

- 支付宝明确写出一笔支出的通知，即使后面带有“领最高金额、满额门槛”优惠，也只提取支出金额。优惠金额不生成账单。
- 通知同时写出两笔不同的实际支出金额、只有优惠没有付款、没有可靠正数金额时，仍不自动记账。

## 使用方法

同签名覆盖安装后，保持“我的 → 设置 → 自动记账”的通知读取权限。若之前漏记的单条通知仍在系统通知栏，监听重新连接时会读取并按通知标识去重；打开首页“待确认金额”核对金额，再自行确认。已经消失的通知无法从系统取回。

- `testDebugUnitTest --tests com.example.lightledger.notification.NotificationParserTest` 通过：19 项，0 失败、0 错误、0 跳过。测试使用虚构金额，包含优惠金额、满额门槛、两笔实际支出及纯优惠通知。
- `assembleRelease` 成功；APK 核对为 versionCode33 / versionName1.0.7、minSdk26、targetSdk35；v2 签名有效，证书 SHA-256 与 1.0.6 相同。
- OPPO PFEM10 / ColorOS 16 从 1.0.6 同签名覆盖安装。系统保留的一条真实支付宝单笔支出通知在监听重新连接后补入账本；“待确认金额”列表显示一笔对应金额、类型为支出、支付方式为支付宝、日期与原通知相符。未替用户确认金额，也未再付款测试。

## 已知限制

- 系统未交给轻账本且已消失的通知无法自动找回。荣耀 X10 Max / HarmonyOS 3 及其他支付宝通知文案本次未真机验证。
- 这次修复识别金额冲突；后台监听能否长期连接仍受系统电池和进程管理影响，不能据此保证所有付款都被投递。
