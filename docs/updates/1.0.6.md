# 轻账本 1.0.6：更清楚的账本界面

更新日期：2026-10-18，北京时间

## 本次变化

- 首页月度金额改为浅色账本式摘要，突出本月实际支出；今日支出和待确认金额有独立层级。
- 账单列表改为紧凑的左右布局，分类与备注在左、金额在右，金额使用等宽数字。批量选择时勾选框替代分类图标，避免挤压文字。
- 新增和编辑账单的金额区、统计摘要以及通用标题、卡片、按钮统一间距与圆角。森林绿、海盐蓝、暖杏橙、雾紫四套配色继续可用。
- 保留分类每行四个、不常用分类默认收起、账单月份切换和现有自动记账流程；没有新增闪烁动画。

## 使用方法

覆盖安装后直接打开首页、账单、统计或“记一笔”即可看到新版界面。主题仍在“我的”中切换。

## 验证结果

- `assembleDebug`、`assembleRelease` 成功，发布 APK 经 `aapt` 核对为 versionCode32 / versionName1.0.6、minSdk26、targetSdk35；`apksigner` 验证 v2 签名有效，证书与 1.0.5 相同。
- 6 项纯逻辑单元检查通过（截图金额解析、商户规则和退款匹配）。本次界面资源与视图绑定已通过编译。
- 布局模拟测试在当前 Windows 测试环境中未完成：Robolectric 读取本地 Android 镜像与原生渲染库时遇到文件访问限制，API29 模拟还出现运行库字段错误。没有将这些环境故障记为界面通过，也未据此判断真机显示效果。
- OPPO PFEM10 / ColorOS 16 已从 1.0.5 同签名覆盖安装 1.0.6，系统显示 versionCode32，通知读取授权仍在。真机查看了首页、账单列表、统计和新增账单；账单主体占据页面主要区域，不常用分类展开后每行仍为四个且可继续滚动。只查看界面，未保存或删除账单，也未进行真实付款测试。

## 已知限制

- 荣耀 X10 Max / HarmonyOS 3、大字体和其他三套主题还需真机查看。账单标题与备注过长时会省略显示，点开账单可查看全文。
- 本次只调整界面；系统未投递或已消失的支付通知仍无法自动补回。
