# 轻账本 0.9.4：最近任务移除后的恢复检查

更新日期：2026-10-12，北京时间

## 本次变化

- 修复划掉时监听仍连接、随后整个进程被清理时，只有15分钟周期检查作为恢复入口的问题。收到最近任务移除回调后安排独立持久化系统检查，即使当时连接正常也保留，最早30秒后执行。
- 断线等待起点保存到本地，恢复任务在新进程里运行时仍沿用原等待时间；避免进程反复重建让一分钟重绑阈值永远达不到。实际连接或撤销权限后清除等待记录，重绑继续保留十分钟冷却。
- 自动记账详情增加本应用的系统最近退出原因、时间、最近任务移除回调及保护服务启动/结束时间。只保存原因类别和时间，不读取退出描述、追踪文件或支付正文。
- 关闭后台保护或撤销通知读取时，取消任务移除检查。后台系统任务处理监听恢复，前台服务启动继续遵守系统限制。

## 使用方法

1. 覆盖安装后打开一次，在“我的 → 自动记账”确认通知读取已允许，后台保护已开启，并点“允许后台运行”确认系统电池豁免。
2. 华为/荣耀或其他机型仍清理应用时，按应用启动管理提供的选项允许自启动和后台运行。
3. 从最近任务划掉轻账本后，如果通知消失或仍漏记，再打开“我的”，点击自动记账状态文字，查看系统最近退出原因、任务移除回调、保护服务与微信/支付宝最近处理结果。无需额外付款才能查看这些状态。

## 已知限制

- 最早30秒是系统任务的最小延迟，不是恢复保证；Doze和厂商限制可能推迟或阻止运行。厂商若在任务移除回调前直接停止应用，无法保证这一检查得到安排。
- 系统可能停止整个包或禁止重新绑定；代码不能保证在所有机型上，划掉后立即恢复。设置“强行停止”后需重新打开应用；后台任务不任意启动受限制的前台服务。
- 系统退出原因在Android11及以上可读取。旧系统只提供应用自身收到的任务/服务回调时间。系统可能没有保留退出记录，记录也可能属于升级前的进程，应核对时间。
- “用户请求”退出原因无法单独区分最近任务移除与强行停止；Android14以前也可能代表更新或组件变化。本版明确保留这种不确定性，不据此断言用户进行了强行停止。
- 当前没有连接手机，没有真机任务划掉、系统清理、真实支付、覆盖升级、长期锁屏或耗电验收。HONOR X10 Max / HarmonyOS3.0和用户手机仍需实机确认。已清除、未产生或没有可靠单笔金额的通知无法补回。
