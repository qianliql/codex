# 轻账本 1.1.2：补查仍在通知栏的付款提醒

更新日期：2026-11-11，北京时间

## 本次变化

- 开启后台保护后，每 30 秒补查一次仍在通知栏的微信和支付宝付款相关通知；仅处理尚未见过的通知，避免反复入账。
- 自动记账诊断单独保留最近 96 条付款相关通知的处理时间与结果，普通聊天不再冲掉付款线索。诊断仍不保存通知正文、金额和商户。

## 使用方法

在“我的 → 设置 → 自动记账”保持通知读取权限和后台保护开启。若发现漏记，尽量保留系统支付通知，打开诊断查看对应时间的付款相关处理结果。

## 验证结果

- `testDebugUnitTest` 全套 293 项通过，0 失败；`assembleRelease` 构建成功。合成通知测试验证：普通两位小数金额可识别；付款通知未触发即时回调、但仍留在通知栏时，补查能处理一次，重复补查不会再处理；后续大量普通聊天不会冲掉付款相关诊断。
- 安装包显示 versionCode37、versionName 1.1.2、minSdk26、targetSdk35；APK v2 签名有效，证书 SHA-256 与 1.1.1 一致。
- 检查旧版真机诊断时，通知读取权限与监听连接处于开启状态；旧记录不足以还原反馈中的那次漏记。本版尚未安装到真机，未进行真实付款验收。

## 已知限制

- 本次反馈的微信通知已经消失，旧诊断也被后续聊天通知覆盖，因此无法确定该笔漏记的具体环节或恢复原金额。本版不会自动补回旧账。
- 补查只能处理系统通知栏仍保留的通知，并依赖后台保护服务运行；系统未送达、已移除或不给出可靠单笔金额的提醒仍无法自动入账。
- 本版未在真实付款或荣耀 X10 Max / HarmonyOS 3 上验证。
