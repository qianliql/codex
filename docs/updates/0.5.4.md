# 轻账本 0.5.4：账单页面空间优化

更新日期：2026-10-10（北京时间）

## 本次变化

- 搜索、记一笔和更多操作移至账单页顶部，与标题共用一行；移除顶部宣传文字和大块操作区域。
- 移除列表下方的“刷新账单”“加载更多”按钮，账单主体直接延伸至底部导航上方。
- 保留顶部下拉刷新；浏览接近列表末尾时自动加载下一页，无需点击按钮。
- 截图导入、待处理账单及手动刷新收进顶部“⋮”菜单。
- 筛选条件缩为一行，可点击修改或清除；长按多选使用紧凑操作栏，保留删除数量确认。
- 自动分页支持普通滚动和直接跳到末尾的布局变化；切换条件或刷新时回到列表顶部，过期查询不再覆盖当前结果。读取失败后停止自动重试，可下拉或从更多菜单刷新。
- 项目维护规则明确每次更新推送GitHub并保留版本报告。

## 使用方法

账单页右上角点“搜索”或“记一笔”。“⋮”提供待处理账单、单张/批量截图导入和刷新账单。列表顶部向下拉即可刷新，往下浏览会自动继续加载。长按一笔进入多选，再点击其他账单勾选，核对数量后删除。
