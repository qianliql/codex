# 轻账本 0.9.1：收入分类与搜索界面优化

更新日期：2026-10-10，北京时间

## 本次变化

- 新增与修改账单切到收入时，默认分类为工资、奖金、生活费、其他，使用两行等宽图标按钮；支出继续使用消费分类。
- 收入主表单显示金额、分类、备注。支付方式、商户、时间和标签收进更多；编辑账单也默认收起更多，隐藏字段仍保留并保存。切换收支时记住各自选择的分类。
- 搜索页将支出、收入两个按钮放在最前面。分类采用录入页的两行图标按钮与横向滚动，支付方式采用微信、支付宝、银行卡、现金四个等宽居中按钮。
- 分类和支付方式旁提供独立清除入口。搜索类型可再次点击取消选择，两个都未选时查询全部类型；不增加第三个类型按钮。
- 账单列表左上角新增返回首页箭头，搜索页左上角返回账单；取消搜索不应用草稿。保留月份切换、顶部放大镜、重置、记一笔和账单主体空间。
- 分类增加收入/支出范围。收入专用分类在管理页单独列出，可改名、改图标、排序和二次确认删除，不占消费分类的通知栏/常用额度。其他默认由收支共用。
- 首次显示搜索页时，提前整理支付按钮尺寸，避免文字挤压。工资、奖金、生活费分别提供工作、礼物、钱包图标。

## 使用方法

新增或编辑账单后选择收入，填写金额、选择分类、添加备注，再保存。需要修改收款渠道、付款方或时间等信息时点更多。已有不符合新分类范围的历史账单，编辑时仍显示原已选分类；只改备注不会自动改分类或支付方式。

搜索账单先选择支出或收入，随后选择分类与支付方式，并可输入商户/备注或设置日期。再次点击已选收支按钮取消该类型限制；点分类或支付方式右侧清除取消该项。点重置清空搜索草稿，点查看账单才应用条件。

账单列表左上角箭头返回首页。收入分类改名或删除在我的→分类管理中操作；删除仍二次确认受影响账单数量，相关账单变为未分类，账单本身与金额、备注保留。

## 已知限制

本次未连接真机，没有进行手机覆盖安装或真实支付验收；HONOR X10 Max / HarmonyOS3.0仍只有布局适配检查。通知格式及系统后台行为仍需使用中观察，监听连接不保证所有付款都有可读取通知。

历史退款与转账仍保留原类型及编辑兼容；搜索页只提供支出/收入按钮，取消类型限制后仍可查询全部历史类型。升级不将历史收入账单的消费分类自动改成工资，也不重写金额或备注。
