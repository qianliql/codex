# 轻账本 0.10.2：自动账单进入待确认金额

更新日期：2026-10-12，北京时间

## 本次变化

- 自动识别到可靠金额的微信、支付宝账单保留金额，同时进入首页“待确认金额”。金额确认与分类状态分别保存，商户自动分类或通知栏选分类不会自动确认金额。
- 点击待确认账单进入“确认金额”，显示识别值和“确认并保存”按钮；可直接确认或修改后确认。更新原账单，不新增重复记录；仅打开再返回不会确认。
- 账单列表显示金额待确认标记，“只看待处理”及“只看待确认金额”均支持新状态；首页数量随确认和删除更新。
- 升级保留已修改过的历史账单，不重新加入待确认；旧自动账单仅未修改的进入待确认，金额、日期、类型、支付方式、备注与分类保留。手动账单和已确认导入账单不因升级进入待确认，原零金额待确认历史账单仍可处理。
- 备份升级到v4，保留独立的金额确认状态，继续读取v1/v2/v3。旧备份中的通知账单仅未修改的按新规则进入待确认。

## 使用方法

1. 同签名覆盖安装，打开一次应用。首页“待确认金额”显示待核对账单数量，跨月查看。
2. 点开账单核对识别金额，正确可直接点“确认并保存”，有误则改正后确认；确认后移出入口，普通账单和统计仍保留记录。
3. 没有可靠正数金额的通知继续跳过，不生成零元记录。日报、月报、汇总与失败消息仍跳过。
4. 备份v4请在0.10.2及之后恢复；恢复仍替换当前账本，先核对备份。旧版不能读取v4。

## 已知限制

- 本次改动修正金额确认流程，仍沿用0.10.1的后台架构。在0.10.1的ColorOS16.0.3 / Android16真机测试中，最近任务划卡会结束页面和监听两个进程，约10.6秒后恢复绑定；进程分离没有阻止该手机的整包清理。这是前一版本现场观察，不能当成本版持续监听验收通过。
- 前版约3分钟USB供电及持续采样观察期间锁屏，未看到新断联；不能代表长时间闲置。系统清理、冻结或强行停止仍可能造成空窗；恢复只能回读保留的通知，不能保证百分百自动记录。
- 长时间闲置、支付宝真实支付、HONOR X10 Max / HarmonyOS3.0及耗电尚未验收；合成通知不能替代真实手机场景。
- 待确认账单仍显示识别金额并参与原有统计，确认修改后统计随原账单更新；待确认不等于金额缺失。
- 旧版没有独立的金额确认标记，迁移及v1/v2/v3恢复依据历史修改时间保留已修改账单；只打开而未保存不算修改。v4直接保留明确的确认状态。
