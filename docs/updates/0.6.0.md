# 轻账本 0.6.0：月份导航、分类优先级与简洁设置

更新日期：2026-10-10（北京时间）

## 本次变化

- 账单页在顶部搜索下方加入月份栏：左右箭头切换月份，点击中间日期直接选择年份和月份。默认查看当前月份；下拉刷新、多选和自动分页继续可用。
- 统计页日期也可点击选择年月；年度模式可快速选择年份，切回月度保留先前选定的月份。
- 年度月均实际支出改为“全年支出减退款 ÷ 有支出或收入记录的月份数”，同月多笔只计一个月。只有收入的月份计入；没有账单、只有退款或只有转账的月份不计入除数。没有参与月份时显示0，并注明暂无收支记录。
- 分类分成通知栏、常用和不常用三档：通知栏最多3个，常用最多8个，不常用默认折叠；支持改名、选择图标、调整档位和组内顺序。
- 通知快捷分类使用你选定的最高优先级分类和顺序，最多三个按钮；点击通知正文仍可选择更多分类。新装默认通知栏分类为正餐、零食、日用。
- 为交通、服饰、手机、饮品、医疗、美容、宠物、运动、旅行、礼物、工作、维修、住房等增加图标，共23种可选图标方案（含自动匹配）。分类管理、记账、搜索、账单和统计使用对应图标。
- 删除家居分类；升级时将该分类的历史账单和商户规则移到其他，保留账单金额、备注、标签和退款关联。恢复旧备份时也进行相同处理。
- “我的→数据管理”仅保留备份账本和从备份恢复，移除CSV导出与追加导入历史账单入口。
- 用户端移除漏记检测、刷新诊断、通知样本记录和检测报告入口；旧样本记录停止并清理，辅助源码保存于仓库archive目录。自动记账监听、重新连接和通知补记保留。

## 使用方法

1. **账单**：点击日期栏左右箭头切换月份；点击中间“年份＋月份”选择目标年月。搜索页可设不限日期或自选范围，日期栏会显示“全部月份”或“自选日期”；使用月份箭头后返回单个月份。更多菜单中的清除筛选保留日期。
2. **统计**：月度模式点击日期选年月，年度模式点击日期选年份；年度卡片会写明参与平均计算的记账月份数。
3. **分类**：我的→分类管理→点击某分类，调整名称、图标和优先级；点击右侧三个点可上移、下移，或删除自定义分类。超过分组容量时提示先将已有分类移到另一组。不常用分类在管理、记账和搜索中均可展开；编辑历史账单时，已选的不常用分类会自动展开。
4. **备份**：我的→数据管理→备份账本，选择本机位置保存。恢复前会显示备份笔数和分类数量并要求确认；恢复替换当前账本。
