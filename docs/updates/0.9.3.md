# 轻账本 0.9.3：最近任务划掉后的监听保护

更新日期：2026-10-12，北京时间

## 本次变化

- 后台保护服务明确不随最近任务页面移除而停止；收到页面划掉回调后检查监听，保持静音常驻通知。
- 修复普通连接请求可能没有实际重新绑定的问题。持续未连接超过一分钟后，Android14及以上尝试系统解绑/重绑，旧安卓刷新本应用监听组件后恢复原启用状态；自动重置间隔至少十分钟。连接正常时不重置。
- 冷启动先显示“正在检查连接”，等待系统连接回调；确实断开或持续没有连接时提示自动恢复。正常监听下反复进入应用不会重启监听。
- 点击“我的 → 自动记账”的状态文字，可查看最近连接动作、微信/支付宝的最近处理结果及成功记账时间。此处不保存通知正文、姓名、订单号或金额，也不恢复旧漏记检测菜单。
- 独立显示后台保护是否运行、状态通知是否可见。下拉通知栏划走状态通知只记录清除动作，不主动停止服务；保护当前未运行时明确显示，不因开关已开启就假定运行正常。

## 使用方法

1. 覆盖安装后打开一次轻账本，在“我的 → 自动记账”确认通知读取已允许。
2. 开启“后台保护”，点“允许后台运行”确认系统电池豁免。开启保护会显示一条静音常驻状态通知。
3. 华为/荣耀若仍清理服务，请在应用启动管理中允许轻账本自启动、关联启动和后台运行；OPPO等机型按系统提供的后台运行设置操作。
4. 之后可从最近任务划掉页面。系统允许服务继续运行时，监听仍处理微信/支付宝发出的可读取支付通知，不需要保留账单页面。
5. 如果漏记，点击自动记账状态查看是未连接、未收到通知、无法确认单笔金额还是保存失败。保留支付通知有助于重连后重读和去重。

Android14及以上允许用户单独划走常驻状态通知。通知消失不代表后台保护已经停止，需查看状态详情；本版不强制反复弹回用户已清除的通知。[Android官方说明](https://developer.android.com/about/versions/14/behavior-changes-all#non-dismissable-notifications)

- 实际Gradle包装器assembleDebug与testDebugUnitTest成功，27套161项检查，0失败、0错误、0跳过。

- 正常监听下多次进入应用不重置或显示重连横幅；冷启动等待回调、持续未连接提醒、连接后隐藏通过。旧安卓恢复原组件状态和中途退出后的状态恢复、自动重新绑定间隔与授权/连接保护通过。
- 状态通知删除PendingIntent、非导出接收器及清除回调检查通过；模拟通知清除后服务和监听继续运行，合成付款保存；保护当前未运行时明确显示。接收器由测试直接调用，不代表真机手势或系统广播投递已验收。
- Android14及以上静态解绑接口使用测试替身记录调用（Robolectric4.17未实现该重载）；验证请求顺序与拒绝后的等待间隔，不模拟实际系统绑定。旧安卓组件刷新也不代表厂商一定恢复监听。
- 原有136项检查继续通过，包括通知金额/汇总过滤、旧新监听实例、保存队列、持久化任务、录入/搜索、分类、统计、迁移与备份。API29/35设置页原生模拟预览已生成并查看，数据管理仍只有备份/恢复。

## 已知限制

- 最近任务划掉与设置中的“强行停止”、前台服务任务管理器的“停止”不同。系统主动停止整个应用时无法承诺继续记账；请重新打开应用。厂商的一键清理可能将最近任务移除视为更强的停止，需允许后台运行。
- 本次没有连接手机，未做真机划掉任务、长期锁屏、真实支付、覆盖升级或电量测量。HONOR X10 Max / HarmonyOS3.0和用户OPPO设备仍需实机验收，模拟通过不代表系统一定保留进程。
- Doze、省电策略和厂商限制仍可能延迟服务恢复与系统任务。已经清除、没有产生或没有可靠正数金额的通知不能补回；日报/月报、汇总和失败/待支付通知仍跳过。
- 后台保护为用户可关闭的前台服务，可能增加后台耗电；没有进行实机耗电对比。不使用循环唤醒、隐藏API或网络保活。
