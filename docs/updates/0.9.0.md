# 轻账本 0.9.0：圆环统计与分类拖动大更新

更新日期：2026-10-10，北京时间

## 本次变化

- 取消自定义页面闪烁、淡入淡出与位移动画，切换页面直接显示。
- 新增账单中的人民币符号和金额统一为36sp粗体；两行分类按钮等宽对齐，四种支付方式文字居中、字号一致；备注输入框缩小，仍支持换行及已有长备注。
- 分类管理每个类别下方的小字去掉；“长按分类，拖到分组调整重要度”集中放在标题下方；去掉设置与配色页面的宣传句。
- 长按分类后，保持按住并拖向底部三个圆角卡片：通知栏、常用、不常用。松手保存，松在目标以外取消；原有点击编辑、菜单排序和删除确认保留。
- 新增/编辑分类弹窗重排为图标预览、名称、三种重要度。通知栏达到3个、常用达到8个时，对应选项和拖动目标直接置灰不可选；已经属于该分组的分类仍可编辑。
- 分类支出改为可点击圆环图，占比严格大于10%的分类独立显示，小于或等于10%的合并为“其他项目”。合并不修改原账单或分类。
- 点击独立分类查看单笔消费排行；点击“其他项目”先列出全部组成分类及金额，再点击某类进入排行。排名按金额从高到低，同金额按时间和ID倒序，显示备注、商户、日期及支付方式，支持分页、点击编辑与修改后刷新。

## 使用方法

1. “我的→分类管理”：点击新增分类，选择图标并输入名称；选择可用的重要度后保存。长按现有分类，拖到下方目标后松手改变重要度。满额目标置灰；先移出一个已有分类即可腾出名额。
2. “首页→统计”：选择月份或年份，向下滑到分类支出，点击圆环或下方分类行查看消费排行。“其他项目”可以查看每个组成分类的完整金额。
3. 消费排行展示选定期间的正数支出账单，备注优先显示。退款、收入、转账不计入分类支出；这里使用总支出、不扣退款，与上方“实际支出”口径不同，页面已注明。
