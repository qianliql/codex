# 轻账本 1.1.4：合并后刷新待确认列表

更新日期：2026-11-16，北京时间

## 本次变化

- 合并保存成功后，账单列表立即移除已选的原账单。从“待确认金额”入口合并返回时，清空旧列表并重新读取，避免原行在刷新期间继续显示。
- 合并依旧以一笔新账单替换所选账单；没有选中的其他账单不会被删除。

## 使用方法

在首页打开“待确认金额”，长按并选中至少两笔同类型账单，点“合并”，核对总额和备注后点“保存并替换”，在确认框中确认。返回后待确认列表会重新读取；新账单可到普通账单列表查看。
