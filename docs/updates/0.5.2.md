# 轻账本 0.5.2：配色、搜索、刷新与漏记辅助

记录日期：2026-10-10（北京时间）。历史报告于2026-10-10根据已有开发/验收记录整理。

## 本次变化

- 提供森林绿、海盐蓝、暖杏橙、雾紫四套配色并保存选择。
- 独立搜索页支持日期、分类、收支、支付方式、标签、来源和待处理条件；可重置或取消草稿。
- 列表顶部下拉刷新，保留筛选，同时提供刷新按钮。
- 简化通知授权入口；系统通知访问详情不可用时回退列表，普通通知使用系统权限请求。
- 提供当前通知检查、默认关闭的本机样本记录、导出和清空；样本最多80条。
- 修正会话标题及消息数占位遮盖当前转账正文的问题。

## 使用方法

根据“本次变化”中的对应页面操作。当前完整安装方法见README.md；旧版报告用于回顾功能演进。

## 验证结果

58项测试通过，包含搜索边界/状态、四套主题、授权回退、本机样本上限及通知结构。该轮无手机实测。

## 已知限制

通知读取必须由用户在系统授权页确认；没有可靠金额的通知仍无法自动生成账单。样本可能含个人信息，仅在本机存储并由用户导出。

## 安装与数据兼容性

0.4.1及之后交付使用同一签名。原电脑0.4.0使用不同签名。升级前导出本地备份，不要自行卸载已有账本。
