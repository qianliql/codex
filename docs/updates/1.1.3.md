# 轻账本 1.1.3：待确认金额也可合并

更新日期：2026-11-12，北京时间

## 本次变化

- 账单多选操作由“聚合”改称“合并”。待确认金额的账单可以和同类型账单一起合并。
- 合并页显示有几笔金额尚待确认。若选中零金额占位账单，合并金额不预填；需输入核对后的总额。保存前再次核对总额，确认后以一笔新账单替换原账单。
- 下载源评估：继续使用GitHub正式版并在Gitee镜像可用时优先下载；尚未验证的新存储源不接入客户端。阿里云OSS需要额外配置并会产生公网下载费用；腾讯云COS新存储桶默认域名不能直接分发APK。详见[应用内更新说明](../app-updates.md)。

## 使用方法

在首页打开“待确认金额”或普通账单列表，长按账单进入多选，选择至少两笔相同收支类型的账单，点“合并”。核对总金额、支付方式和备注后点“保存并替换”，在确认框中再次确认。原账单会被新账单替换，操作无法撤销。

- 安装包显示versionCode38、versionName 1.1.3、minSdk26、targetSdk35；APK v2签名有效，证书SHA-256与1.1.2一致。本版尚未安装到真机或进行真实账单操作。

## 已知限制

- 待确认金额只有原通知提供的估计值，合并时需由用户核对；零金额占位账单不会自动推算原金额。关联退款的账单仍不能合并。
- 本版尚未在真机上验收合并操作，亦未进行真实付款测试。新下载源只完成方案评估，未切换应用的正式下载地址。
