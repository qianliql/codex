# 轻账本 0.5.0：卡片界面与不同屏幕适配

记录日期：2026-10-09（北京时间）。历史报告于2026-10-10根据已有开发/验收记录整理。

## 本次变化

- 首页使用暖白背景、渐变收支卡和快捷入口。
- 分类矢量图标、账单层次、统计刻度与空状态、底部导航样式统一。
- 处理系统栏、屏幕缺口、键盘避让、不同密度和放大字体。
- 新增HONOR X10 Max / HarmonyOS3.0的1080×2280布局目标。

## 使用方法

根据“本次变化”中的对应页面操作。当前完整安装方法见README.md；旧版报告用于回顾功能演进。

## 验证结果

26项测试通过；模拟API29/35，生成1080×2280原生预览，并检查320dp窄屏、1.3倍字体与键盘空间。

## 已知限制

没有荣耀真机；模拟布局不能代表HarmonyOS通知访问、锁屏后台或OCR已通过。

## 安装与数据兼容性

0.4.1及之后交付使用同一签名。原电脑0.4.0使用不同签名。升级前导出本地备份，不要自行卸载已有账本。
