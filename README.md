# 轻账本 · LightLedger

个人使用的离线Android记账软件，支持手工记账、微信/支付宝通知读取、本地截图识别和支出统计。当前版本 **0.9.4**，最低Android8.0（API26）。

## 下载与安装

在[版本下载页](https://github.com/qianliql/codex/releases/latest)下载`LightLedger-0.9.4-debug.apk`，传到手机后点开安装即可，无需连接电脑。允许当前下载或文件管理应用安装未知来源的软件后，按系统提示安装。

0.4.1及之后的原交付使用相同签名，可覆盖同签名版本。原电脑0.4.0签名不同；如果系统提示签名不一致，请先导出并验证本地备份，再处理迁移，避免清空账单。

首次打开或升级后打开一次应用，在“我的 → 自动记账”允许通知读取。需要长期后台使用时开启“后台保护”（静音常驻状态通知），并点“允许后台运行”确认系统电池豁免；华为/荣耀还需允许应用启动管理中的后台运行。系统授权由用户确认。

## 主要功能

- 新增/修改账单，金额与人民币符号同字号加粗；两行分类、一行居中的支付方式、小型备注框，收入使用工资/奖金/生活费/其他，支付方式收进更多；新增/编辑的更多默认收起。页面切换取消自定义闪烁动画。
- 分类名称与图标、长按直接拖到重要度卡片和组内排序；通知栏最多3个、常用最多8个，满额目标置灰，不常用默认折叠。所有实际分类可删除，二次确认后相关账单归为未分类并保留原账单；账单长按多选删除。
- 微信和支付宝支付通知本地解析；没有可靠正数金额或属于日报/月报、汇总、失败/待支付消息时跳过。
- 单张或批量截图离线中文OCR；确认识别结果与处理相似账单。
- 底部只保留首页和我的，首页进入账单/统计；账单左上角返回首页；顶部放大镜搜索、邻接重置、记一笔、下拉刷新与自动分页，正常显示时账单主体超过三分之二。
- 搜索收支类型前置为支出/收入两按钮，分类与支付方式统一录入页样式，支持独立清除；取消类型限制可查看全部历史类型。
- 后台监听断开自动退避重连，系统任务支持进程重建与重启后的恢复；可开启后台保护，显示静音常驻状态通知。提供电池豁免授权与后台运行指引，持续断开时可从横幅修复；重连读取保留的通知并去重。长时间未连接时升级为重新绑定，正常连接不重置；支持最近任务移除回调，状态详情区分监听、保护服务和通知可见状态，并显示本应用系统退出原因及服务/任务时间；最近任务移除后安排独立持久化恢复检查，断线等待跨进程保留。
- 账单和统计快速选择年月；月度/年度/分类/支付方式统计，年度平均按有收支记录的月份计算。分类支出圆环图中占比严格大于10%的分类独立显示，其余归入其他项目；点击查看所有组成分类及单笔消费排行，保留备注、商户和日期，支出不扣退款。
- 四套可切换并保存的主题配色：森林绿、海盐蓝、暖杏橙、雾紫。
- JSON本地备份与恢复（导出v3，支持v1/v2/v3读取）；恢复会替换当前本机数据，使用前核对备份。v3保留分类范围及删除结果，请在0.9.1或之后版本恢复；旧v1/v2非空备份会补齐新增收入分类，空分类列表保持为空。
- 升级和恢复旧备份时，家居账单及对应商户规则自动归入其他。漏记辅助代码存档于archive目录，不参与App编译。

App不需要账号、不申请INTERNET权限，中文OCR模型随安装包提供。仓库及安装包不包含个人账单、备份或签名私钥。

## 开发

Kotlin、XML、Room、ViewModel、RecyclerView。金额以整数分存储。使用JDK17及AndroidSDK36，Gradle8.13；minSdk26、targetSdk35。

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest
```

macOS/Linux使用`./gradlew assembleDebug testDebugUnitTest`。通过AndroidStudio配置SDK，或在本地`local.properties`中填写SDK路径；该文件不要提交。

在新电脑自行构建会使用本地调试签名，与发布安装包未必相同。维护已安装版本时须沿用保存在本地的签名；不要将私钥提交到仓库。
