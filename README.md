# 轻账本 · LightLedger

个人使用的离线Android记账软件，支持手工记账、微信/支付宝通知读取、本地截图识别和支出统计。当前版本 **0.5.4**，最低Android8.0（API26）。

## 下载与安装

在[版本下载页](https://github.com/qianliql/codex/releases/latest)下载`LightLedger-0.5.4-debug.apk`，传到手机后点开安装即可，无需连接电脑。允许当前下载或文件管理应用安装未知来源的软件后，按系统提示安装。

0.4.1及之后的原交付使用相同签名，可覆盖同签名版本。原电脑0.4.0签名不同；如果系统提示签名不一致，请先导出并验证本地备份，再处理迁移，避免清空账单。

新手机首次打开，在“我的”中开启通知访问。系统必须由用户确认授权；快捷分类通知另需允许轻账本发送通知。

## 主要功能

- 新增/修改账单，分类改名、标签及商户规则，长按多选并确认批量删除。
- 微信和支付宝支付通知本地解析；没有可靠正数金额或属于日报/月报、汇总、失败/待支付消息时跳过。
- 单张或批量截图离线中文OCR；确认识别结果与处理相似账单。
- 历史账单JSON追加导入，保留已有数据，重复导入跳过已导入记录，支持原分类与备注。
- 顶部搜索与记一笔，多条件筛选、下拉刷新、滚动自动加载；账单页主体至少占页面三分之二。
- 月度/年度/分类/支付方式统计。
- 四套可切换并保存的主题配色：森林绿、海盐蓝、暖杏橙、雾紫。
- CSV导出、JSON本地备份与恢复；恢复会替换当前本机数据，使用前核对备份。
- 本机漏记诊断与可选通知样本记录，默认不记录通知正文；启用后最多80条，可自行导出和清空。

App不需要账号、不申请INTERNET权限，中文OCR模型随安装包提供。仓库及安装包不包含个人账单、备份或签名私钥。

## 开发

Kotlin、XML、Room、ViewModel、RecyclerView。金额以整数分存储。使用JDK17及AndroidSDK36，Gradle8.13；minSdk26、targetSdk35。

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest
```

macOS/Linux使用`./gradlew assembleDebug testDebugUnitTest`。通过AndroidStudio配置SDK，或在本地`local.properties`中填写SDK路径；该文件不要提交。

在新电脑自行构建会使用本地调试签名，与发布安装包未必相同。维护已安装版本时须沿用保存在本地的签名；不要将私钥提交到仓库。

## 验证范围

0.5.4的67项检查通过；模拟API29/35检查1080×2280布局、320dp窄屏、大字体和键盘，普通/筛选/多选账单状态主体占比均超过三分之二（含底部导航，授权横幅隐藏）。自动分页与多选、刷新及待处理筛选组合已检查。此次没有连接真机；0.5.3曾在OPPO Find X5 Pro验证安装、历史导入与备注显示，早期版本曾观察真实微信支付及断开USB后台场景。

HONOR X10 Max / HarmonyOS3.0为布局适配目标，目前无该型号真机验收。近期版本的所有微信/支付宝通知格式、长期锁屏和电量表现仍需使用中观察。详见[验证说明](docs/verification.md)。
