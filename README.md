# 轻账本 · LightLedger

个人使用的Android记账软件，支持手工记账、微信/支付宝通知读取、本地截图识别和支出统计。账单、通知和截图在本机处理；联网仅用于检查和下载公开版本。当前版本 **1.0.0**，最低Android8.0（API26）。

## 下载与安装

首次安装可在[版本下载页](https://github.com/qianliql/codex/releases/latest)或[Gitee安装包镜像](https://gitee.com/qianlihuo/money/releases)下载`LightLedger-1.0.0-debug.apk`，传到手机后点开安装，无需连接电脑。文件名保留 `debug` 是为了兼容旧版更新器，安装包实际使用压缩后的 release 构建并沿用原签名。已安装0.11.0及后续版本时，可从“我的 → 设置 → 检查更新”在应用内下载新版，随后按系统提示允许轻账本安装并确认升级。应用打开后也会定期检查新版本；下载和安装由用户决定。

0.4.1及之后的原交付使用相同签名，可覆盖同签名版本。原电脑0.4.0签名不同；如果系统提示签名不一致，请先导出并验证本地备份，再处理迁移，避免清空账单。

首次打开或升级后打开一次应用，在“我的 → 设置 → 自动记账”允许通知读取。需要长期后台使用时开启“后台保护”（静音常驻状态通知），并点“允许后台运行”确认系统电池豁免；华为/荣耀还需允许应用启动管理中的后台运行。系统授权由用户确认。

## 主要功能

- 新增/修改账单，金额与人民币符号同字号加粗；分类按两列换行完整显示、不常用分类单独常显，金额以小数点开头时自动补 0；一行居中的支付方式、小型备注框，收入使用工资/奖金/生活费/其他，支付方式收进更多；新增/编辑的更多默认收起。页面切换取消自定义闪烁动画。
- 打开已有账单时先显示编辑标题，资料加载好后才显示表单；编辑返回账单列表时保留原来的浏览位置。
- 分类名称与图标，点击分类可调整重要度；通知栏最多3个、常用最多5个，满额选项置为深灰且不可选，不常用单独常显。所有实际分类可删除，二次确认后相关账单归为未分类并保留原账单；账单长按多选删除。
- 微信和支付宝支付通知本地解析，自动填写对应支付方式并记住最近识别结果供手动新增预选；没有可靠正数金额或属于日报/月报、多笔汇总、失败/待支付消息时跳过。支付宝只有一笔明确付款内容的汇总通知可作为单笔处理，仍需真机验证。
- 1.0.0把通知识别、去重与保存按到达顺序放在后台处理，并在“自动记账”诊断中显示最近一次通知的识别、入库和快捷提示耗时；正式安装包为22,264,092字节，保留离线中文OCR。安装包支持32/64位ARM手机。
- 单张或批量截图离线中文OCR；确认识别结果与处理相似账单。
- 首页“待确认金额”快捷入口与实时笔数，跨月查看自动识别账单及已有零金额待确认账单；保留识别金额，核对后确认并移出入口，搜索支持同一筛选。
- 底部只保留首页和我的，首页进入账单/统计；账单与统计左上角返回首页；顶部放大镜搜索、邻接重置、记一笔、下拉刷新与自动分页，正常显示时账单主体超过三分之二。
- 搜索收支类型前置为支出/收入两按钮，分类与支付方式统一录入页样式，支持独立清除；取消类型限制可查看全部历史类型。
- 页面与后台监听分进程运行，私有接口获取连接/保护状态，后台账单变化同步页面。后台监听断开自动退避重连，系统任务支持进程重建与重启后的恢复；可开启后台保护，显示静音常驻状态通知。提供电池豁免授权与后台运行指引，持续断开时可从横幅修复；重连读取保留的通知并去重。长时间未连接时升级为重新绑定，正常连接不重置；支持最近任务移除回调，状态详情区分监听、保护服务和通知可见状态，并显示本应用系统退出原因及服务/任务时间；最近任务移除后安排独立持久化恢复检查，断线等待跨进程保留。
- 账单和统计快速选择年月；月度/年度/分类/支付方式统计，年度平均按有收支记录的月份计算。收入和支出各有总额及分类圆环图，占比严格大于10%的分类独立显示，其余归入其他项目；点击查看所有组成分类及单笔排行，保留备注、商户和日期，支出不扣退款。
- 四套可切换并保存的主题配色：森林绿、海盐蓝、暖杏橙、雾紫。
- “我的”保留主题、分类、标签和商户规则，增加设置入口与版本号；设置页集中管理自动记账、备份恢复和软件更新。检查新版后可在应用内下载，校验文件大小、SHA-256、包名、版本、系统要求和签名，最终由系统安装界面确认。
- JSON本地备份与恢复（导出v4，支持v1/v2/v3/v4读取）；恢复会替换当前本机数据，使用前核对备份。v4保留分类范围、删除结果与金额确认状态，请在0.10.2或之后版本恢复；旧v1/v2非空备份会补齐新增收入分类，空分类列表保持为空。
- 升级和恢复旧备份时，家居账单及对应商户规则自动归入其他。漏记辅助代码存档于archive目录，不参与App编译。

App不需要账号。更新功能使用INTERNET和REQUEST_INSTALL_PACKAGES权限读取公开GitHub版本信息、下载安装包并调用系统安装；账单、备份、支付通知、诊断与中文OCR不上传。中文OCR模型随安装包提供。仓库及安装包不包含个人账单、备份或签名私钥。更新机制和发布要求见[应用内更新说明](docs/app-updates.md)。

## 开发

Kotlin、XML、Room、ViewModel、RecyclerView。金额以整数分存储。使用JDK17及AndroidSDK36，Gradle8.13；minSdk26、targetSdk35。

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest
```

macOS/Linux使用`./gradlew assembleDebug testDebugUnitTest`。通过AndroidStudio配置SDK，或在本地`local.properties`中填写SDK路径；该文件不要提交。

在新电脑自行构建会使用本地调试签名，与发布安装包未必相同。维护已安装版本时须沿用保存在本地的签名；不要将私钥提交到仓库。
